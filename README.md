# Lynn Portfolio - 陈琳个人作品集

## 项目简介

这是陈琳（Lynn）的个人作品集网站，展示产品设计、数据分析能力及项目经验。

## 技术栈

- React 18
- Vite
- Lucide React (图标库)

## 本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 功能特点

- 🎨 中国山水画美学设计
- 🌏 中英文双语支持
- 📱 完全响应式布局
- ✨ 优雅的交互动画
- 🔗 集成飞书文档链接
- 📲 社交媒体链接

## 项目结构

```
lynn-portfolio/
├── src/
│   ├── App.jsx          # 主组件
│   └── main.jsx         # 入口文件
├── index.html           # HTML模板

└── README.md            # 说明文档
```
